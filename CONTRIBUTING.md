# Contributing

Read the [development guide](doc/development.md) and
[licensing policy](doc/licensing.md) before contributing.

Use small commits that build independently. Separate behavior-preserving
extraction from format changes and Abuild integration. Include tests that
would detect a violation of the documented contract.

Submit new project-owned contributions under BSD-3-Clause. Retain copyright
and licence notices for imported material. Do not submit third-party source
under BSD-3-Clause unless its existing terms or an explicit grant permit it.

The repository is private during bootstrapping. Public releases, Alire
publication and the transfer to the project organization are separate owner
decisions.
