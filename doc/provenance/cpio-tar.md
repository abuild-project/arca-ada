## Technical split

The production packages use Ada/GNAT facilities; CPIO and TAR both use the
shared copy helper. Import only helper operations with actual consumers.
The endian serializers currently serve partition-table code and are outside
the first archive extraction.

CPIO's direct writer checks are embedded in the transformation test unit:
raw device headers, raw record layout, unopened close, timestamp rejection
and oversized writer input. The misleadingly named `Reject_Unopened_CPIO_Add`
actually invokes the transformation and must stay in Abuild. Preserve the
other transformation tests there as integration checks.

TAR's test unit also mixes direct writer checks with transformation cases.
Its raw headers, boundaries, payload copying, independent readers and
parallel writer checks are extraction candidates. Cases using
`Run_Transformation` retain an Abuild integration role.

Do not import the shared Tests root, Paths, configuration, file-object
collections, transformation factory or process wrapper just to compile the
existing test units. Adapt the independent checks to an Arca-owned harness.
The raw block reader also needs an ordinary pathname boundary instead of
`Abuild.Paths.Path_Type`.
